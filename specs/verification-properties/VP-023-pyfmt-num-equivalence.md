# VP-023: pyfmt number semantics equivalent to CPython 3.11 on oracle tables

## Property Statement

For the entire closed helper set — `Round` (ties-to-even + decimal re-round), `RoundN`,
`F` ('f' format incl. -0 and nan/inf spellings), `D`, `Int`, `Ceil`,
`FloorDiv`/`Mod` (the CPython `float_divmod` port, not `math.Floor(a/b)`),
`FloorDivInt/ModInt`, `Max`/`Min` (first-maximal-wins NaN argument order), `MaxSeq`,
`Repr` (shortest round-trip, .0 suffix, inf/nan spellings), `ParseInt`/`ParseFloat`
(Python grammar: underscores, Unicode digits, 4,300-digit limit, 1e400) — the Go
implementation agrees with the committed CPython 3.11-generated expectation tables, and
beyond-int64 durations stay byte-exact via `math/big` at exactly the two ruled
duration-format sites (OD-137).

## Source Contract

- **Primary BC:** BC-5.01.001 — Round/RoundN/F: half-even, decimal re-round, 'f'
  format incl. -0; nan/inf/-inf spellings.
- **Partial coverage:** BC-5.01.002 (ParseInt/ParseFloat grammar), BC-5.01.003
  (divmod/typed NaN/Overflow, Max/Min NaN order), BC-5.01.004 (D), BC-5.01.005 (Repr),
  BC-5.01.006 (MaxSeq).
- **Invariant verified:** NFR-003 substrate (banned Go stdlib codecs on protocol
  inputs); AD-04 (CPython-generated tables, banned stdlib on protocol inputs);
  FMA-sensitivity disposed by `// pyfmt: no-fuse` sites run on arm64 (IM-10/PR-15).

## Property Class and Verification Method

- **Class:** invariant.
- **Method:** property-based + oracle tables — every helper carries a committed
  CPython-generated table (OD-142 regime: regenerated by script, no hand-recorded
  literals); property generators sample int64/big.Int/float64/bool corners; four
  helpers get `go test -fuzz` targets (Decode, DumpsLen, FromISOFormat, ParseFloat per
  design §2.6 — num-side: ParseFloat).
- **Honesty (iron law):** this is the strongest provable-grade surface in the repo
  (ARCH-06), yet still empirical: closed functions + exhaustive-pinned corners +
  random sampling — not a formal proof. No Kani/TLA+ artifact is claimed for Go here.

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| Oracle tables | Go test, `internal/pyfmt/testdata/*.golden` | yes — committed tables | every helper, corner-pinned |
| Property generators | Go test | no (random), seeded | value-space sampling; oracle = self-consistency invariants (e.g. `Repr(ParseFloat(r))` spelling stability, divmod identity `a*b ≡ FloorDiv*a + Mod*a` for finite a), never a live interpreter call — CPython equivalence is pinned only by the committed tables |
| Fuzz | `go test -fuzz` (ParseFloat et al.) | budget-bounded | grammar acceptance |
